# App Support

Static support and privacy pages for apps by CiiN.

All app and game support/privacy pages are maintained in this repository. Add each app under its own directory and link it from `index.html`. Reuse the shared `styles.css`; do not introduce a separate theme, stylesheet, or hosting project for an individual app. The existing GitHub Pages workflow publishes the site from `main`.
